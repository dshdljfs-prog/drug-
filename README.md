# عقاراتي — موقع عقارات عربي

موقع واجهة أمامية متجاوب مبني باستخدام HTML وCSS وJavaScript، مناسب للنشر على GitHub Pages.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح لمعاينة الموقع.
3. ارفع الملفات الثلاثة (`index.html`, `style.css`, `app.js`) إلى مستودع GitHub.
4. من إعدادات المستودع اختر **Pages** ثم النشر من فرع `main` ومجلد `/root`.

## لوحة التحكم
- اضغط «لوحة التحكم».
- رمز الدخول الحالي: `01276461885`
- إضافة وتعديل وحذف العقارات.
- نوع العقار، بيع/إيجار، السعر، المساحة، الموقع، الغرف والحمامات، وصف الإعلان.
- رقم الوسيط الخاص بكل عقار، وزر تواصل واتساب مباشر.
- رفع صور متعددة للعقار.
- أربعة ثيمات جاهزة.
- حفظ البيانات والإعدادات في `localStorage` على نفس المتصفح.

## تنبيه مهم قبل الاستخدام التجاري
هذه نسخة Front-end فقط. رمز لوحة التحكم موجود داخل `app.js` ويمكن لأي شخص لديه معرفة تقنية رؤيته، كما أن العقارات والصور محفوظة محلياً في المتصفح ولا تتزامن بين الزوار أو الأجهزة. لا تستخدم هذه النسخة وحدها لإدارة بيانات حقيقية أو لحماية لوحة تحكم عامة. لتشغيل تجاري آمن، انقل تسجيل الدخول والبيانات ورفع الصور إلى Backend وقاعدة بيانات وخدمة تخزين، مع صلاحيات للمشرف. يمكن استخدام Supabase أو Firebase لذلك.

## الصور
يمكن رفع صور حتى 1.5MB للصورة الواحدة لتقليل امتلاء مساحة المتصفح. استخدم صوراً مضغوطة. الصور التجريبية في الصفحة تحتاج اتصالاً بالإنترنت.
